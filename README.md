# 스미싱 탐지 분류기 (가상 프로젝트)

> 본 저장소는 포트폴리오를 위해 기획·설계한 가상 프로젝트 문서입니다.

## 1. 프로젝트 배경 및 목적

최근 택배 배송, 부고장, 기관 안내 등을 사칭한 스미싱 피해가 꾸준히 발생하고 있습니다. 기존에는 특정 단어를 차단하는 방식을 주로 사용했지만 띄어쓰기를 교묘하게 바꾸거나 단축 URL을 사용하는 등 차단 기능을 우회하는 사례가 늘어나고 있습니다.

본 프로젝트는 단순 단어 차단의 한계를 보완하기 위해 한국어 문자의 텍스트 패턴과 특징을 데이터로 분석하고 머신러닝으로 스미싱 여부를 판별하는 분류 모델을 기획·설계하는 것을 목표로 합니다.

## 2. 전체 진행 흐름

1. **데이터 수집 및 구성**
   - 일상적인 정상 문자 데이터와 실제 신고 사례 기반의 스미싱 문자 데이터를 수집해 학습용 데이터셋을 구성합니다.
2. **텍스트 전처리**
   - 파이썬 `Pandas`로 결측치와 중복 데이터를 정리합니다.
   - 한국어 형태소 분석기(`KoNLPy`)를 사용해 문장에서 의미 없는 기호나 조사를 제거하고 핵심 단어(명사, 동사 등)만 추출합니다.
   - 문자 내 URL 포함 여부, 특수문자 비율 같은 구조적 특징도 함께 정리합니다.
3. **모델 학습 및 분류**
   - 정리된 텍스트 데이터를 `Scikit-learn`을 이용해 컴퓨터가 이해할 수 있는 수치 형태로 변환합니다.
   - 정상 문자와 스미싱 문자의 단어 패턴을 학습시켜 새로운 문자가 입력되었을 때 스미싱일 확률을 계산합니다.
4. **결과 및 위험 요소 안내**
   - 단순히 '스미싱 여부'만 알려주는 것이 아니라, **스미싱 의심 확률**과 **판단에 영향을 준 주요 위험 단어**를 함께 출력합니다.
